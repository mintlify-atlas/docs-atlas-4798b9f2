Binary Internals is an open-source Java toolkit that lets you look inside binary files and understand the meaning of every byte. Whether you're debugging a corrupted `.class` file, exploring how an Android `.dex` is structured, or integrating binary parsing into your own project, Binary Internals gives you the tools to do it interactively and programmatically.

## What Is Binary Internals?

Binary Internals parses binary files and exposes their structure as an interactive tree. Each node in the tree corresponds to a specific byte range in the file, complete with its start offset, length, and a human-readable description of what those bytes mean.

The project ships in three forms:

- **`BinaryInternalsViewer`** — a desktop Swing application for opening and inspecting files interactively
- **`BinaryInternalsWeb`** — a lightweight HTTP server exposing the same parsing capability as a REST API, with a built-in web UI
- **`FormatXXXX` JARs** — standalone parsing libraries (`FormatCLASS`, `FormatZIP`, `FormatBMP`, etc.) you can embed directly in your own Java project

<Note>
Binary Internals has **zero third-party runtime dependencies**. It runs on JDK 11+ and relies entirely on the standard library.
</Note>

## Get Started

<Steps>
  <Step title="Download the viewer JAR">
    Grab the latest `BinaryInternalsViewer-x.x-timestamp.jar` from the [GitHub Releases](https://github.com/amosshi/binaryinternals/releases) page.
  </Step>
  <Step title="Run it">
    ```bash
    java -jar BinaryInternalsViewer-3.7-timestamp.jar
    ```
    Use **File → Open…** or drag and drop any supported binary file onto the window.
  </Step>
  <Step title="Explore the tree">
    Every node in the tree maps to a specific byte range. Click a node to see its offset, length, and description in the detail panel.
  </Step>
  <Step title="Go further">
    Run the [web server](/quickstart-web) for API access, or [embed a format JAR](/developer/standalone-libs) directly in your Java project.
  </Step>
</Steps>
